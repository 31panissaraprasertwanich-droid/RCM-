Transformer Failure Code Reference

T008 น้ำมันรั่วซึมที่ Cable box ซีลเสื่อมสภาพ / ติดตั้งไม่ตามมาตรฐาน / ความร้อนสูงเกินไป
T009 น้ำมันรั่วซึมที่ Radiator ซีลเสื่อมสภาพ / ติดตั้งไม่ตามมาตรฐาน / แรงดันภายในสูง / การเสื่อมจากสิ่งสกปรก
T012 น้ำมันหม้อแปลงต่ำ ระบบระบายความร้อนทำงานผิดปกติ / ซีลเสื่อมสภาพ

T303 Oil filter unit มีน้ำมันรั่วซึม ซีลเสื่อมสภาพ
